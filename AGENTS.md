# AGENTS.md

## Objetivo
Este projeto prioriza código legível, testável e fácil de evoluir.

## Regras gerais
- Prefira simplicidade antes de abstração.
- Evite duplicação, mas não force generalização prematura.
- Preserve comportamento ao refatorar.
- Mantenha funções pequenas e responsabilidades claras.
- Escreva testes para alterações relevantes.
- Antes de mudanças grandes, proponha um plano curto.
- Em dúvidas de arquitetura, preserve separação entre domínio, aplicação e infraestrutura.
- Quando houver oportunidade clara, sugira o uso de skills específicas para refatoração, SOLID, clean code ou clean architecture.
