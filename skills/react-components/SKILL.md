# React components

Use this skill when creating or refactoring React components.

## Rules
- Prefer functional components.
- Keep components small and focused.
- Extract custom hooks when logic grows.
- Avoid unnecessary re-renders and prop drilling.
- Use composition before inheritance or over-abstracted patterns.
- Keep side effects inside hooks.

## React guidance
- Keep state as local as possible.
- Derive data instead of duplicating state.
- Prefer clear prop contracts.
- Handle loading, empty, and error states explicitly.
- Preserve accessibility with semantic elements and proper labels.
