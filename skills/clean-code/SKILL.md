# Clean code skill

Use this skill when the goal is clearer, more maintainable code.

## Core rules
- Use meaningful names.
- Keep functions short and focused.
- Minimize nesting.
- Make control flow easy to follow.
- Avoid duplication.
- Prefer explicitness over cleverness.
- Keep side effects visible and contained.

## Review checklist
- Can the code be read quickly?
- Are names self-explanatory?
- Is each function doing one thing?
- Is the module cohesive?
- Is the code easy to test?

## Preferred actions
- Rename ambiguous identifiers.
- Extract helper functions.
- Flatten nested conditionals.
- Replace magic values with constants or types.
- Remove dead code.
